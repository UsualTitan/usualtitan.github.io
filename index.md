# UsualTitan

I'm an offensive security practitioner with roots in **web and API penetration testing**, holding both the **OSCP** and **eWPTX** certifications. I've spent years breaking web applications and APIs for a living, understanding how systems fail so defenders can build them better.

Recently, I started asking a different question: _what happens when the system being attacked is an AI model?_

That question led me to pursue the **[Certified Offensive AI Expert (COAE)](https://academy.hackthebox.com)** certification from HackTheBox — and this blog is what came out of it.

---

## What this blog is about

AI security is moving fast and the learning resources are still catching up. Most content out there is either too theoretical for practitioners or too shallow to be actually useful. I wanted something in between **hands-on, honest, and beginner-friendly without being dumbed down**.

So I'm documenting everything:

- 📝 **HTB COAE Writeups** — every challenge, every mistake, every fix, with full explanations of the underlying concepts
- 🧠 **Knowledge articles** — practical deep dives into AI attack techniques (data poisoning, adversarial examples, model theft, and more) for people who want to understand not just _how_ but _why_
  I'm not an AI researcher. I'm an offensive security practitioner learning this space the same way I learned web hacking — by breaking things and writing about it. If you're coming from a pentesting background and want to understand AI security, or if you're curious about this field and don't know where to start, this is written for you.
